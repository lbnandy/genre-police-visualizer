# Genre Police Visualization 0.1.0 Beta

[简体中文](#简体中文) · [English](#english) · [日本語](#日本語)

## 简体中文

Genre Police Visualization 会识别 Windows 当前播放的音乐曲风，并随之切换可视化结构、背景和动态表现。当前版本以 EDM 为主，部分曲风仍在继续补充和调整。

### 下载

- `Genre-Police-Visualization-0.1.0-portable.exe`
- `SHA256SUMS.txt`

本版适用于 Windows 10/11 x64，下载 EXE 后即可运行，不需要另行安装 Node.js、Python、PyTorch 或 AI 运行环境。

### 主要功能

- 胶囊型与海报型两种布局，设置分别保存。
- 根据曲风切换可视化、背景、字体、粒子和动态表现。
- 支持系统播放信息、媒体控制、同步歌词、逐字高亮和歌词翻译（如可用）。
- 内置本地 BeatNet ONNX 节奏分析；系统音频不会被录制、保存或上传。

> 0.1.0 暂未进行 Authenticode 代码签名，Windows SmartScreen 可能显示“无法识别的发布者”。请只从本项目的 GitHub Releases 下载，并使用 `SHA256SUMS.txt` 核对文件。

## English

Genre Police Visualization identifies the genre of the music currently playing on Windows, then changes its visualization structure, background, and motion. This beta currently focuses on EDM, and some genre designs are still being expanded and refined.

### Download

- `Genre-Police-Visualization-0.1.0-portable.exe`
- `SHA256SUMS.txt`

This portable build supports Windows 10/11 x64. Download and run the EXE; Node.js, Python, PyTorch, and a separate AI runtime are not required.

### Highlights

- Capsule and poster layouts with independently saved settings.
- Genre-aware visualization structures, backgrounds, typography, particles, and motion.
- Windows media information and controls, synchronized lyrics, word or character highlighting, and lyric translation when available.
- Bundled local BeatNet ONNX rhythm analysis; system audio is never recorded, saved, or uploaded.

> Version 0.1.0 is not Authenticode-signed, so Windows SmartScreen may show an “Unknown publisher” warning. Download it only from this project's GitHub Releases and verify it with `SHA256SUMS.txt`.

## 日本語

Genre Police Visualization は、Windows で再生中の音楽ジャンルを識別し、ビジュアライザーの構造、背景、モーションを切り替えるデスクトップ音楽ビジュアライザーです。現在のベータ版は EDM を中心としており、一部のジャンル表現は引き続き追加・調整中です。

### ダウンロード

- `Genre-Police-Visualization-0.1.0-portable.exe`
- `SHA256SUMS.txt`

Windows 10/11 x64 対応のポータブル版です。EXE をダウンロードしてそのまま実行でき、Node.js、Python、PyTorch、追加の AI 実行環境は必要ありません。

### 主な機能

- カプセル型とポスター型の 2 種類のレイアウト。設定はレイアウトごとに保存されます。
- ジャンルに応じてビジュアライザーの構造、背景、書体、パーティクル、モーションを切り替えます。
- Windows のメディア情報と操作、同期歌詞、単語または文字単位のハイライト、歌詞翻訳（利用可能な場合）に対応します。
- ローカルで動作する BeatNet ONNX リズム解析を内蔵。システム音声を録音、保存、アップロードすることはありません。

> バージョン 0.1.0 は Authenticode 署名を行っていないため、Windows SmartScreen に「不明な発行元」と表示される場合があります。本プロジェクトの GitHub Releases からのみダウンロードし、`SHA256SUMS.txt` でファイルを確認してください。
