# Security policy

## Supported versions

The current `0.1.x` test release receives security and dependency updates. Older development snapshots are not supported.

## Reporting a vulnerability

Use GitHub private vulnerability reporting when it is available for this repository. If private reporting is unavailable, open an issue asking for a private contact channel without publishing exploit details.

Do not include Last.fm API keys, Discogs tokens, diagnostic files containing information you do not intend to share, or any other credentials in a public issue.

For ordinary bugs and feature requests, use the repository issue templates. The exported Genre Police diagnostics file intentionally excludes API credentials, track metadata, artwork, lyrics, and listening history.
